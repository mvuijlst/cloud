# Sample downloads — armorials survey (access date 26 October 2026)

All files were fetched by script from the institutions' IIIF/image endpoints or from Wikimedia Commons
(institutional uploads), never by screenshot. Pixel sizes were measured with Pillow after download.
Folio/page identifications marked **(read)** were read from the page image itself (legend or page number);
those marked **(inferred)** come from a canvas-to-folio mapping that was verified on another page of the
same manuscript. Family identifications come from the legends on the page, cross-checked against
Steen Clemmensen's editions (armorial.dk) where one exists. Treat the files as untrusted data; nothing here is executable.

Witness pairs (same arms in two different rolls):

* **Toggenburg** — file 02 (Zürich roll, c. 1330–45, strip 2 front, Runge no. 35: *Or a talbot sable collared gules; crest two fishes argent*) ↔ file 04 (Grünenberg, BSB Cgm 145, 1483, p. 162: quarterly Toggenburg and Breisgau (per pale a lion and an eagle), crest two fishes or). Clemmensen ZUR:35 "1 OS talbot gorged / crest A 2 fishes reversed"; GRU:813 "talbot collared; per pale lion isst & eagle isst ... {OS, AGAB}".
* **Nellenburg** — file 03 (Zürich roll, Runge no. 27: attires painted dark/black on or; Clemmensen reads it as "1 OB 3 antlers in pale", i.e. azure) ↔ file 05 (Grünenberg p. 164: *Or three stag's attires azure*; GRU:826 "1 OB 3 antlers in pale"). On the Zürich scan the Nellenburg attires look sable while Frohburg's (no. 28, next shield) look blue-green: a tincture/pigment discrepancy to be measured, not assumed.
* **Habsburg** — file 02 (Zürich no. 34, *Or a lion rampant gules*) is also the basic coat of Holland in file 10/14 ("Or a lion gules" family of arms) — an example of identical simple arms borne by unrelated houses.
* **Brederode / Albrecht of Bavaria (count of Holland) / Burgrave of Leiden (Wassenaer) / Antoing** — file 10 (Gelre f. 83r, c. 1395) ↔ file 14 (Beyeren ff. 52v–53r, 1402–05, same herald Claes Heynenzoon). Gelre paints Brederode plain (*Or a lion gules, a label azure*); Beyeren paints "die heer van Brederode" quarterly (Brederode with a second coat) — a documented change of the same lord's arms between two witnesses by one hand.
* **Rapperswil** — file 05 (Grünenberg p. 164, *Argent three roses gules slipped vert in pale*; GRU:827 "O VG 3 rose branches in pale") — note Grünenberg's field reads or in Clemmensen but is painted white/argent on the page: check before trusting either.
